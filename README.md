# Expense Splitter

A [Chickadee Bandit](https://chickadeebandit.com/app-library/expense-splitter) app.

Track shared expenses among household members — who paid, how to split the cost, and who owes whom. Log expenses by category with a receipt, settle up with one tap, and see a running balance per person. In a shared space, either party can request a reimbursement that both sides countersign.

## Features

- Log expenses by category with who paid and a receipt.
- Split evenly, by exact amounts, or by a saved per-category rule.
- Running balance per person.
- Repeating expenses such as rent: set the payer, split and schedule once. Each occurrence is added to the ledger the next time an adult opens the app, dated the day it was due. An optional email reminder goes out before each due date while someone keeps opening the app. If nobody opens it for a whole period, reminders wait until someone does.
- In a shared space, countersigned reimbursement requests.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-expense-splitter/releases/latest/download/bundle.json
```
